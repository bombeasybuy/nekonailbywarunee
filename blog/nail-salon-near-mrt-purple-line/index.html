MRT PURPLE LINE • BANG YAI

ร้านทำเล็บใกล้ MRT สายสีม่วง เดินจาก Skywalk ตลาดบางใหญ่ไม่เกิน 3 นาที

กำลังหาร้านทำเล็บ ใกล้ MRT สายสีม่วง ที่เดินทางง่ายอยู่ใช่ไหมคะ? Neko Nail by Warunee อยู่ชั้น 1 ภายใน Index Living Mall บางใหญ่ ลง MRT สายสีม่วง สถานีตลาดบางใหญ่ แล้วเดินตาม Skywalk มาฝั่ง Index Living Mall จากจุดลง Skywalk เดินต่อประมาณไม่เกิน 3 นาทีค่ะ

ปลายทางของเรา — Index Living Mall บางใหญ่ จากเส้นทาง Skywalk ของ MRT ตลาดบางใหญ่เดินต่อมาได้สะดวกค่ะ

วิธีเดินทางมาร้าน Neko Nail จาก MRT สายสีม่วง

เส้นทางนี้ใช้ MRT ตลาดบางใหญ่ + Skywalk เป็นหลัก เหมาะกับคนที่มาจากสถานีอื่นตามแนวรถไฟฟ้าสายสีม่วงและอยากเดินมาร้านโดยไม่ต้องต่อรถค่ะ ภาพด้านล่างเป็นภาพเส้นทางจริงเพื่อช่วยสังเกต Landmark ระหว่างทาง

1

ลง MRT สายสีม่วง สถานีตลาดบางใหญ่

เมื่อถึงสถานีตลาดบางใหญ่ ให้มุ่งไปยังทางเชื่อม Skywalk ฝั่งบางใหญ่ จากบริเวณสถานีจะมองเห็นอาคารและ Landmark รอบ Central Westgate ได้ชัดค่ะ

จุดเริ่มต้นจาก MRT สายสีม่วง สถานีตลาดบางใหญ่

2

เดินตาม Skywalk โดยใช้ Central Westgate เป็น Landmark

เดินต่อบน Skywalk จะเห็น Central Westgate ได้ง่าย ใช้เป็นจุดสังเกตว่ากำลังอยู่ในเส้นทางถูกฝั่งค่ะ

ระหว่างเดินบน Skywalk จะเห็น Central Westgate เป็น Landmark ชัดเจน

3

มองฝั่งตรงข้าม จะเห็นป้าย Index Living Mall

เมื่อเดินมาในแนว Skywalk ให้สังเกตป้าย Index Living Mall ขนาดใหญ่ฝั่งตรงข้าม Central Westgate เห็นป้ายนี้แล้วถือว่าใกล้ถึงมากค่ะ หากเดินทางมาจาก MRT ตลาดบางใหญ่ ตามเส้นทางนี้จะถึง Index Living Mall บางใหญ่ก่อน BB Market Park ค่ะ

ป้าย Index Living Mall เป็น Landmark สำคัญก่อนลงจาก Skywalk

4

ลงจาก Skywalk ฝั่ง Index Living Mall

เดินลงจาก Skywalk ฝั่งที่มุ่งมายัง Index Living Mall แล้วเดินต่ออีกประมาณ ไม่เกิน 3 นาที ก็ถึงห้างค่ะ ระยะเวลาจริงอาจต่างกันเล็กน้อยตามจังหวะการเดิน

ลงจาก Skywalk ฝั่งนี้แล้วเดินต่ออีกเพียงช่วงสั้น ๆ ถึง Index Living Mall บางใหญ่

สรุปสำหรับคนค้นหาร้านทำเล็บใกล้ MRT สายสีม่วง: ลงสถานีตลาดบางใหญ่ → เดิน Skywalk → สังเกต Central Westgate และป้าย Index Living Mall → ลง Skywalk → เดินต่อไม่เกินประมาณ 3 นาที → ถึง Index Living Mall บางใหญ่ค่ะ
